# Kingdom of Code

Интерактивное фэнтезийное портфолио: всадник едет по дорогам между семью замками. Каждый замок открывает раздел портфолио.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite. Сборка:

```bash
npm run build
npm run preview
```

Нужен современный настольный браузер с WebGL: Chrome, Edge или Firefox.

## Управление

- `W A S D` или стрелки — ехать и поворачивать
- Клик по дороге — маршрут
- Клик по замку — ехать к нему, рядом с воротами клик или `Enter` открывает раздел
- Колесо мыши — масштаб
- Перетаскивание — ненадолго сдвинуть камеру
- `Esc` — закрыть окно
- Кнопка Return — вернуться к старту по дорогам

## Где менять данные

Все тексты, проекты, опыт, навыки и контакты: `src/config/portfolioData.ts`.

Пустые ссылки специально отключены. Кнопка включается, когда в поле появляется настоящий адрес.

Карта, дороги и замки: `src/config/worldConfig.ts`.

## Модель, музыка и звуки

- Музыка: положи свой трек в `public/audio/music.mp3`. Если файла нет, игра молчит и пишет подсказку в консоль.
- Модель героя: положи `public/models/hero.glb` и укажи путь в `src/config/assets.ts` (`heroModel`). Пока путь пустой, используется встроенная модель из `src/game/hero/Hero.tsx`.
- Копыта, ветер и щелчки интерфейса собираются в браузере в `src/game/audio/AudioManager.ts`, отдельные файлы для них не нужны.
